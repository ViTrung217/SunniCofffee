# Ảnh bổ sung SuniCoffee

24 ảnh tạo bằng built-in image_gen cho các SKU còn dùng ảnh nhóm; 12 ảnh cũ được giữ. File JPEG dùng trên website nằm tại src/main/resources/static/images/products. Prompt và ánh xạ từng SKU ở manifest.json. Bộ ảnh là minh họa thiết kế cho danh mục đồ án được chủ dự án chấp thuận ngày 15/10/2026; chữ trang trí trên bao bì không phải thông số được kiểm nghiệm. Ảnh admin tải lên được ưu tiên.
