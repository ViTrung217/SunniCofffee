# Kiểm tra trước khi chốt chỉ chạy local

Bằng chứng giữ nguyên từ lúc thử cấu hình máy chủ trong quá trình rà soát. Cấu hình triển khai đã được loại khỏi bản bàn giao theo yêu cầu chỉ chạy local. Không dùng số kiểm thử hoặc hash JAR trong thư mục này làm số liệu của bản cuối; xem các tệp cấp trên. Kiểm tra đơn hàng/COD và restore dùng dữ liệu tổng hợp ở MySQL riêng, không chạm dữ liệu người dùng.
